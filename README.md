# VetAnesthesiaApp

This app is now the technical foundation for `VetPulse`.

## Current Role

The MAUI app in this folder is the working anesthesia workflow base for the broader VetPulse product:

- voice-first vital entry
- anesthesia charting
- validation and audit-friendly data handling
- PDF export
- offline-first local storage

## Product Direction

VetPulse is being developed as a focused anesthesia workflow layer that sits beside the clinic's current software.

The commercial direction is integration-first, Android-first, and pilot-driven.
